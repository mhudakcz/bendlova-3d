# Bendlova 16A · 3D

Interaktivní 3D model rodinného domu Bendlova 16A v Brně podle původní dokumentace (arch. Oldřich Blažek, 1948) a obrysu z OpenStreetMap.

- 3D náhled domu s okolím (OSM)
- izolace podlaží, vodorovný a svislé řezy
- procházení domem (šipky / WASD, tažení myší)
- galerie původních výkresů

Rozměry a dispozice: `src/house.ts` (v cm).

```bash
npm install
npm run dev
```

Data okolí © přispěvatelé OpenStreetMap (ODbL).
